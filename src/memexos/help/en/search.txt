memex search "<question>" [--kw "<keywords…>"] [-n 8] [--mode auto|fast|keyword|vector|deep] [--json] [--inbox]

  auto (default): the question goes to vector search (when qmd is set up) and the keywords to a BM25 keyword index; the two
  result lists are fused by rank, and the top candidates are reranked by asking whether each page contains the information
  needed to answer, not merely the same topic. Without qmd it uses the built-in keyword index.

  --kw     2–5 keywords you picked, in the language the pages are written in ($language): in one --kw separated by
           commas (--kw "rank fusion, RRF") or spaces (a phrase in quotes: --kw '"rank fusion" RRF'), or one --kw per
           keyword (--kw "rank fusion" --kw RRF). Without --kw they are guessed from the question, usually less precisely
  -n       how many results (default 8)
  --mode   fast: fused results without reranking · keyword: keyword index only (milliseconds; works in read-only sandboxes)
           vector: vector search only · deep: qmd's query expansion + reranker (slowest)
  --json   output for programs: {"degraded": [...], "keywords": [...], "hits": [{"path", "title", "kind",
           "classification", "compiled_page", "sources", "matched", "snippet"}]}
  --inbox  also search inbox/ (notes left for people, often outdated; excluded by default)

  Examples
    memex search "how are vector and keyword results combined" --kw "rank fusion RRF"
    memex search "what does the reviewer check before publishing" --kw "gate 2 review"

  Reading the results
    [topic]/[concept]/[entity]/[source] is a wiki page; [raw source] is a file in raw/, followed by the wiki page it was
    compiled into: read that page first. A raw file whose page is already in the results is left out.
    "class" gives a source's domain, content type, evidence strength and caveats; "rests on N sources" says how many
    sources a wiki page cites. "contains" lists the keywords found in the page; "found by meaning" means none of them
    are in it, so check it really answers the question. A line starting with ⚠️ means search ran in a reduced way
    (for example without vectors) and says why.
