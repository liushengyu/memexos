## 你的任务：出 $n 道「正确使用」类题

这类题考的是：Agent 会不会看来源的**分类**（`.memex/catalog.jsonl` 和来源页 frontmatter 里的 `evidence` 证据强度、`content_type` 内容类型、
`durability` 时效、`domain` 领域、`use_note` 注意事项；`memex catalog list --help` 列出筛选方式）来决定**能不能这样用**。
好的题目：答对**必须**依据分类信息，单看正文的事实会答错或答得过头。例如：
- 一个来源是第三方转述或营销推广，正文里的数字写得很肯定 → 问“这个数字能当实测结论写进报告吗”
- 一个来源是作品展示，只演示效果没讲做法 → 问“照它的做法能复现吗”
- 一个来源时效短（某个版本、某个时点）→ 问“现在还是这样吗”
- 一个来源属于别的领域 → 问“这个结论能不能套过来”
- 问“库里有没有一手实测的 X 数据”，需要按证据强度筛来源才能答

先找到合适的来源页，**确认正文里没有直接写出这个使用限制**（写了的话这题不考分类，换一个），再出题。gold_pages 写这些来源页，
key_facts 写正确答案的要点，use_rule 写正确用法。覆盖不同领域。只读，严格按 JSON schema 输出 {"items": [...]}，type 一律为 usage。
