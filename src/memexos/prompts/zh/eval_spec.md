# 检索测评：一道题由什么组成

检索测评衡量的是：任何 Agent 用这个知识库时，能不能找到对的内容、并且正确地用它。每道题都带金标准：

- `type`：`fact`（一页里的一个事实）、`synth`（要综合几页）、`usage`（答对取决于来源的分类：证据强度、适用范围、时效）、
  `negative`（看起来相关、但库里确实没有答案）、`real`（用户在过去的会话里真实问过的问题）
- `gold_pages`：答这道题要用到的 wiki 页面（相对知识库的路径，如 `wiki/concepts/提示词缓存.md`）
- `gold_raw`：这些页面引用的原始资料
- `key_facts`：正确答案必须包含的要点，每条一句、可以核对
- `answerable`：只有 negative 题（以及库里答不了的真实问题）为 false
- `use_rule`：usage 题要求的正确用法（例如“必须说明这是第三方转述”）
- `domain`：题目所属领域；`why`：一句话说明这道题考什么、为什么难或容易

措辞要像真人提问：口语、只给关键词、简称、中英混合都要有。不能照抄页面标题或页面里的句子，否则测的是字面匹配，不是检索。
