# Anki

A free flashcard program, first released in 2006, that schedules reviews with a variant of [[SM-2]]
([[How spaced repetition works]]).

- Since Anki 23.10 (2023) users can switch to FSRS, a scheduler that fits a memory model to the user's own review
  history instead of fixed rules.
